# Portfolio

## Building Blocks

- [`React`](https://react.dev) (with [`Vite`](https://vitejs.dev))
- [`Typescript`](https://www.typescriptlang.org/)

---

## Scripts

#### Start the development server:

```bash
npm dev
```

#### Start the production server:

```bash
npm start
```

#### Build For Production:

```bash
npm build
```

#### Preview Production Build:

```bash
npm preview
```
